# 🎯 注音符號自主練習 APP

這是一個專為 iPad 打造的互動式注音符號練習工具，支援聽音辨字、繪圖寫字與星星計分功能。

## 🔗 線上使用網址
👉 [點此開啟注音練習工具](https://henryak520.github.io/bopomofo/)

## 📱 使用說明
1. 請確保 iPad 已連上網路（Wi-Fi 或行動網路）。
2. 使用 Safari 瀏覽器開啟上方網址：https://henryak520.github.io/bopomofo/
3. 點擊 Safari 右上角 **「分享 (📤)」➔「加入主畫面」**，即可在桌面生成專屬 App 圖示。
4. 點擊桌面圖示即可開啟練習（⚠️ 本網頁版本需在連網狀態下使用）。
