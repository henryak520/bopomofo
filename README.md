# 🎯 注音符號自主練習 APP

專為 iPad 與兒童打造的互動式注音符號學習工具，支援 37 音點讀發音、聽音辨字、筆順描紅手寫練習、自訂練習題數與星星獎勵機制。

## 🔗 線上使用網址

👉 **[點此開啟注音練習工具](https://henryak520.github.io/bopomofo/)**

---

## ✨ 核心功能特色

* 🔊 **37 音真人點讀看板**：首頁提供完整的 ㄅㄆㄇ 37 音符號點讀卡，點擊即可收聽高清真人發音。
* ✍️ **ㄅㄆㄇ 描紅手寫練習**：支援手寫畫布，可自由切換「米字引導線」與淡灰色描紅字體，方便孩子照著筆順摹寫。
* 🔘 聽音選字卡 (選擇題)**：播放發音並提示選項，訓練注音聽力辨識。
* 📝 **聽寫魔法板 (手寫題)**：家長或系統出題，孩子於畫布手寫回答，並提供家長批量批改與對答案功能。
* ⚙️ **自訂練習題數**：家長可自由設定每次練習題數（範圍 1 ~ 100 題），靈活安排學習份量。
* 🎵 **真實語音優化**：單個注音發音採用高品質真人錄音檔（WAV 格式），2-3 字詞語則搭配電腦語音朗讀。
* ⭐ **星星獎勵與錯題本**：答對題目獲取星星，可於「獎勵兌換中心」兌換實體獎勵；答錯題目自動納入錯題本加強特訓。

---

## 📱 使用說明 (iPad / 手機 / 平板)

1. 請確保設備已連上網路（Wi-Fi 或行動網路）。
2. 使用 **Safari** 瀏覽器開啟上方網址：`https://henryak520.github.io/bopomofo/`
3. 點擊 Safari 右上角的 **「分享」** 圖示 $\rightarrow$ 選擇 **「加入主畫面」**，即可在桌面生成專屬 App 圖示。
4. 點擊桌面圖示即可開啟練習（⚠️ 本網頁版本需在連網狀態下使用）。
